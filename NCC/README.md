# NCC Workspace

This workspace is the NCC strategy pack for the 2026 National Conference on Communications and related UCC proposal work.

It now lives inside the final-year project repository by explicit human direction. Keep it distinct as supervisor-facing strategy, proposal, and publication material; `ProjectReport.md` at the repository root remains the implementation/report source and should not be overwritten from NCC drafts.

## Structure

- `sources/`: archived public pages, PDFs, and the source manifest.
- `analysis/`: decision-driving briefs based on the archived sources.
- `paper/`: non-draft writing skeletons, evidence planning, title bank, and abstract placeholders.
- `feedback/`: proposal feedback artifacts, extracted WhatsApp feedback, action matrices, and feedback recordings.

## Ground Rules

- Do not edit or overwrite the repository-root `ProjectReport.md` from NCC proposal drafts.
- Log every new source in `sources/manifest.csv`.
- Prefer official NCC and UCC sources first, then public winner artifacts, then carefully chosen secondary sources.
- Keep claims evidence-backed and date-stamped.
- Treat unpublished or non-public reviewer identities as unknown; use public proxies only.

## Confidence Scale

- `high`: official NCC, UCC, Makerere/CEDAT, MMU, BSU, IEEE CTU, or direct winner artifact.
- `medium`: public but secondary recap, public library catalog entry, or public profile that is not the primary institutional record.
- `low`: discoverable lead worth following up, but not yet fully validated.

## Current Working Position

- Primary NCC paper framing: infrastructure-first, around denoising noisy edge-of-coverage GSM signals to extend effective service reach.
- Backup framing: AI/ML-first, around robust denoising and classification under low-SNR Uganda conditions.
- Public 2026 reviewer list is not visible, so the decision-maker map uses public proxies from NCC, UCC, and the host institution.
