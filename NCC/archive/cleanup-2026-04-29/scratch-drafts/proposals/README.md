## Shared rules

- Both drafts use the same core story: improve effective GSM service reach in rural Uganda through AI-assisted signal denoising and weak-signal interpretation.
- Both drafts treat basic `2G` handsets as the primary end-user reality. Any Android + SDR path is framed as a prototype, capture, or field-support tool rather than the only user-facing deployment model.
- Both drafts keep `Dr. Dickson Mugerwa` and `Dr. Ephrance` visible as supervisory leads, while preserving student authorship as primary.
- Both drafts follow the citation and evidence discipline already established in the `NCC` analysis pack.

- `OFF-*`: official UCC / NCC / conference sources from [manifest.csv](/Users/sharif/telecom/final-year-project/NCC/sources/manifest.csv)
